# VulnLab Test Cases - Quick Reference Card

## ⚡ Quick Commands

```powershell
# Basic check with VulnLab tests
.\webview_check.ps1 app.apk

# Advanced analysis (detailed)
python check_webview_advanced.py app.apk -v

# JSON report (for automation)
python check_webview.py app.apk --json

# Save to file
python check_webview.py app.apk -o report.txt

# Generate Frida hooks
python example_workflow.py app.apk --generate-hooks
```

- ✅ All 9 OWASP vulnerabilities

- ✅ Code injection vulnerabilities

1. **OWASP Mobile Top 10 Vulnerabilities**

   - Name and CVSS score
   - Keywords detected
   - Test commands

2. **WebView Analysis**
   - WebView found status
   - JavaScript enabled
   - File access permissions
   - Storage settings
   - Custom clients

3. **Security Recommendations**
   - Specific fixes for each issue
   - Code remediation examples
   - Best practices

## 🎯 Key Features

**CVSS Scoring**
- 9.0+ = CRITICAL 🔴
- 7.0-8.9 = HIGH 🔴  
- 5.0-6.9 = MEDIUM 🟠

**Detection Methods**
- Manifest scanning

- API usage detection

## 💡 Example Usage

```powershell
# Check your app
.\webview_check.ps1 myapp.apk

# Get detailed findings
python check_webview_advanced.py myapp.apk -v

# Export for reports
python check_webview.py myapp.apk --json -o findings.json

# Generate test scripts
python example_workflow.py myapp.apk --generate-hooks
```
